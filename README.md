# NotizZettel

## Beschreibung

NotizZettel ist eine Progressive Web App (PWA) für Laptop und Smartphone.

Ziel ist eine einfach zu bedienende Notiz- und Aufgabenverwaltung mit lernender Textvorschlagsfunktion.

---

## Funktionen

- Notizen hinzufügen
- Notizen abhaken
- Notizen löschen
- Automatisches Speichern
- Automatisches Laden
- Lernendes Wörterbuch
- Textvorschläge während der Eingabe
- Optimiert für Samsung-Smartphones
- Nutzung auf Windows und Android
- GitHub-Synchronisation (in Entwicklung)

---

## Geplante Funktionen

- Handschrifterkennung
- Spracheingabe
- Synchronisation zwischen Laptop und Smartphone
- PWA-Installation
- Wörterbuchverwaltung
- Datensicherung
